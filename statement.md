# StudyMate Pro - Project Statement

## 1. Problem Statement

College students have to manage many things at the same time, such as subjects, assignments, exams, notes, class schedules, reminders, goals and study habits. When this information is kept in different apps or notebooks, it can become difficult to stay organized. Students may forget deadlines, lose track of their tasks or find it difficult to understand how much progress they have actually made.

## 2. Proposed Solution

StudyMate Pro is a Java Swing desktop application developed to bring these academic activities together in one place. Students can manage their subjects and tasks, keep study notes, maintain their schedule, track exams and goals, set reminders and record their daily habits. The application also shows progress and productivity information based on the student's stored activities.

## 3. Target Users

- College and university students
- Students managing multiple subjects, assignments and exam deadlines
- Students who prefer a simple offline desktop application for planning and tracking their studies

## 4. Scope

StudyMate Pro covers subject management, task and assignment management, exam management, study notes, weekly schedules, reminders, goals, habit tracking, progress reports, achievements, rule-based task suggestions and local data storage.

The current version is designed as a **single-user offline desktop application**. Features such as multi-user login, cloud synchronization, mobile access and operating-system notifications after the application is closed are outside the current scope and can be considered for future development.

## 5. Objectives

1. Apply Java and object-oriented programming concepts in a practical project.
2. Implement multiple useful CRUD-based modules.
3. Develop a graphical user interface using Java Swing.
4. Handle user input through validation and appropriate error handling.
5. Store application data locally without requiring a database server.
6. Calculate useful progress and productivity information from stored data.
7. Use a simple rule-based approach to suggest tasks that may need attention.
8. Maintain a modular project structure and follow basic software development and version-control practices.

## 6. High-Level Features

- Live academic dashboard
- Add, edit and delete subjects
- Add, edit, delete and complete tasks
- Create, edit and delete study notes
- Maintain weekly schedule entries
- Create, complete and delete reminders
- Add, edit and delete exams with countdown information
- Goal creation and progress tracking
- Daily habit tracking with streaks and a yearly activity heatmap
- Progress and productivity reports
- Automatically calculated achievements
- Rule-based recommended study tasks
- Local data persistence
- Input validation

## 7. Expected Outcome

StudyMate Pro provides students with a single offline application for organizing their academic activities and keeping track of their progress.

The project also demonstrates practical use of **Java, OOP, GUI development, file-based data storage, validation, business logic and software testing**.

The Habit Tracker provides a visual way of seeing completed activities over time. By seeing their progress and streaks build up, students can get a better sense of their consistency and stay motivated to continue their study habits.
